# 실제 AI(Claude) 연결 설정 가이드 — 관리자용

이 문서는 **API 키를 설정해 실제 AI 분석을 처음 실행하기까지의 절차**와 보안 주의사항이다. 키가 없는 동안에는 화면이 'AI 설정 필요'만 표시하고 기존 규칙 기반 기능이 그대로 동작한다.

## 1. 지원 설정(공식 문서 확인 2026-10-27)

| 항목 | 값 |
|---|---|
| 모델 ID | `claude-sonnet-5-5` (Anthropic 공식 모델 문서의 API ID, 컨텍스트 1M 토큰·최대 출력 128K) |
| 요청 | Messages API `POST https://api.anthropic.com/v1/messages`, 헤더 `x-api-key`·`anthropic-version: 2023-06-01` |
| thinking | **`thinking` 필드를 보내지 않는다.** Sonnet 5.5는 기본이 적응형 사고이며 `thinking: {type: "disabled"}`는 400 오류다. 사고 토큰은 출력 토큰으로 과금되고 `max_tokens`에 포함되므로 출력 한도를 12,000토큰으로 둔다. 응답의 `thinking` 블록은 버리고 `text` 블록만 분석 결과로 쓴다. |
| 출력 JSON | 기본: 프롬프트 기반 JSON + 서버의 스키마 검증(`validate_payload`)과 원문 근거 대조. 선택: `AI_STRUCTURED_OUTPUT=1`이면 `output_config.format`(json_schema)을 함께 보낸다 — 공식 문서상 지원되나 **실제 호출로 검증하지 못했으므로 첫 호출 검증이 끝난 뒤에만 켠다**. |
| 종료 사유 | `max_tokens`(잘림)는 파싱하지 않고 실패로 기록하되 사용 토큰은 남긴다. `refusal`도 실패로 기록한다. |
| 사용량 | 응답의 `usage.input_tokens`/`output_tokens`를 저장하고 단가표로 비용을 '계산'한다(제공자 청구금액과 구분). |

OpenAI는 이 환경에서 공식 문서 페이지를 대조하지 못해(접근 403) 기본 모델을 두지 않는다. 사용하려면 `AI_MODEL`을 직접 지정하고 별도 점검이 필요하다.

## 2. 키 설정 절차(로컬 환경변수)

키는 **서버 환경변수로만** 읽는다. DB·화면·요청 본문·로그·GitHub에 저장하지 않는다.

1. `apps/api/.env`(저장소에 커밋되지 않음)에 아래 줄을 추가한다. 값 부분에 실제 키를 넣고, 이 파일을 메신저·이슈·채팅에 붙여넣지 않는다.

   ```
   AI_PROVIDER=anthropic
   ANTHROPIC_API_KEY=<발급받은 키>
   # AI_MODEL=claude-sonnet-5-5   # 비우면 기본값
   AI_DAILY_LIMIT=30
   # AI_MAX_COST_PER_REQUEST_USD=0.30   # 요청당 전역 예산 상한(권장)
   ```

   또는 PowerShell에서 현재 세션에만 설정한 뒤 서버를 시작한다.

   ```powershell
   $env:AI_PROVIDER="anthropic"; $env:ANTHROPIC_API_KEY="<발급받은 키>"
   ```
2. 서버를 다시 시작한다(환경변수는 시작할 때 읽는다).
3. 설정 화면의 **'AI 분석 설정·사용량'** → **'연결 진단'**을 누른다. 키로 조회한 모델 목록에 `claude-sonnet-5-5`가 있으면 '확인됨'이다(토큰을 쓰지 않는 모델 목록 조회). 키가 없거나 틀리면 '연결 미검증'/오류 코드가 표시되며 **성공으로 표시하지 않는다.**
4. 설정 화면의 **단가표**에서 `claude-sonnet-5-5` 단가(기본 입력 $2 / 출력 $10, 기준일 2026-10-27)가 현재 공식 가격표와 같은지 확인하고 다르면 갱신한다. 단가가 없으면 비용은 '계산 불가'로 표시되고 실제 호출은 차단된다.

## 3. 키 보안 주의

- 키 값은 오류 메시지·저장된 응답·상태 화면에서 자동으로 `[REDACTED]` 처리되지만, 키를 직접 공유하지 않는 것이 원칙이다.
- 키가 노출됐다고 의심되면 제공자 콘솔에서 즉시 폐기·재발급하고 서버 환경변수를 갱신한다.
- 공개 GitHub Pages(`/preview/`)에는 키가 없고 AI 호출도 없다. AI 분석은 인증된 로컬 통합 사이트에서만 실행된다.
- CI에서는 실제 AI를 호출하지 않는다(모의 공급자 `AI_PROVIDER=mock`만 사용).
- Claude Code 개발 세션의 인증정보는 이 플랫폼의 AI 키로 쓰지 않는다. 별도 API 키를 발급받아 사용한다.

## 4. 첫 실제 호출 전 확인(체크리스트)

1. `docs/AI_VALIDATION_PLAN.md`의 대상·예상 비용을 사용자가 검토하고 **비용을 승인**한다.
2. 연결 진단 '확인됨', 단가표 확인 완료.
3. **첫 분석 대상은 FCC 'Upper C-Band (3.98–4.2 GHz); Expanding Flexible Use of the 3.7 to 4.2 GHz Band'(https://www.federalregister.gov/d/2026-21324, 통신·네트워크)** 1건이다. 해당 원문 상세 화면에서 'AI 분석 요청' → 관리자는 **'첫 호출 사전 점검'**(유료 호출 없음; 키가 있으면 무료 Token Counting API로 실제 입력 토큰 실측)으로 전달 형식·토큰·최대 계산 비용을 확인한다.
4. 사전 점검의 권장 상한(제안: **$0.15 이내**)으로 **'이 1건 호출 승인'**(예산 상한, 1회용·60분 유효)을 누른다. 서버는 승인 상한·전역 상한과 **최대 계산 비용(실측 입력 토큰 + 출력 상한 12,000토큰)**을 비교해, 넘으면 호출 전에 차단한다. 무료 토큰 계산이 실패(인증·모델 오류)하면 유료 호출을 하지 않고 승인도 소모하지 않는다.
5. 실행 → 실제 토큰·계산 비용·오류를 확인한다. 호출이 실패해도 승인은 소멸하므로 같은 승인으로 자동 재시도되지 않는다(새 승인 필요).
6. 결과의 원문 근거를 대조하고 '품질 평가'(7개 항목)를 저장한다. 다음 문서는 다시 승인한 뒤에만 분석한다.

## 5. 비용 구분

- **예상 비용**: 호출 전 토큰 추정치 × 단가표(상한 가정 출력 5,000토큰).
- **계산 비용**: 호출 후 응답의 실제 토큰 × 단가표.
- **제공자 청구금액**: 제공자 콘솔의 실제 청구액 — 이 플랫폼은 알 수 없으며 위 두 값과 다를 수 있다.
- 이미 제공자에게 전달된 요청은 취소해도 비용이 발생할 수 있다(취소 = DB 상태만 취소). 그래서 호출 전 한도·승인을 우선한다.

## 6. 무료 시연 버전 — 유료 호출은 코드 수준으로 차단됨

사용자 결정: **이 플랫폼은 시연용이며 유료 AI 호출은 절대 하지 않는다.** 따라서 `ai_service.PAID_AI_DISABLED = True`로 Anthropic·OpenAI 공급자 생성 자체를 막고, HTTP 계층에서도 `api.anthropic.com`·`api.openai.com` 요청을 네트워크로 나가기 전에 차단한다.
- API 키가 있어도, `AI_PROVIDER`·`AI_ALLOW_PAID` 등 어떤 환경변수를 설정해도 호출되지 않는다(관리자 화면의 연결 진단·호출 승인·사전 점검·단가 설정도 비활성화).
- 한 공급자가 막혀도 다른 유료 공급자로 자동 전환하지 않는다. 공식 뉴스·정책자료 수집용 일반 HTTP 요청은 막지 않는다.
- 다시 유료 기능을 쓰려면 **환경변수가 아니라** 코드 변경(위 상수와 관련 테스트 수정·검토·배포)이 필요하다. CI는 유료 호출을 하지 않는다(모의 공급자 `AI_PROVIDER=mock`만 사용, 화면에 '모의 응답(테스트용) — 실제 LLM 분석 아님' 표시).
- 위 1~5절은 향후 유료 사용을 결정할 때를 위한 참고 자료일 뿐 현재 버전에서는 동작하지 않는다.
