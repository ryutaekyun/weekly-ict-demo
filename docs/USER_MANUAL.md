# 사용자 매뉴얼 (연구원용, Phase 4-1)

## 시작하기
1. 로그인 화면의 **회원가입**에서 이름·이메일·비밀번호(10자 이상, 영문+숫자)를 입력한다. 관리자 초대 링크를 받았다면 링크로 접속해 초대받은 이메일로 가입한다(즉시 사용 가능).
2. 초대 없이 가입하면 **관리자 승인 후** 로그인할 수 있다. 승인 전에는 "관리자 승인 대기 중" 안내가 표시된다.
3. 로그인하면 **통합 대시보드**가 열린다. 오늘 신규 수집자료, 검토 대기 후보주제, 내가 작성 중인 원고, 정보원 수집 오류가 상단에 보이고, 아래에 최근 수집 뉴스·관심 분야 최신 동향·주요 이슈·우선 검토 후보주제·나의 할 일·검토 요청·최근 작업 이력이 이어진다.

## 내 정보
오른쪽 위 이름 → **내 정보**: 이름·직함, **관심 ICT 분야**(대시보드 '관심 분야 최신 동향'에 반영), 비밀번호 변경.

## 메뉴
- 조사: ICT 정보 수집 · 핵심 이슈 분석 · 후보주제 선정·검토
- 집필·발간: 연구·집필 작업실 · 보고서·요약본 · 카드뉴스 · 후속 규정 알림 · 주간기술동향지
- 관리: 출처·수집 관리 · (관리자) 사용자 관리 · 설정 · 서비스 소개

## 관리자
**사용자 관리**에서 가입 승인·거절(역할 지정), 역할 변경, 계정 비활성화, 초대 링크 발급을 한다. 초대 링크는 발급 직후 한 번만 표시되므로 복사해 직접 전달한다(메일 자동 발송 없음). 마지막 관리자 계정은 비활성화할 수 없다.

## 역할
시스템 관리자 · 연구원 · 검토자 · 편집·승인 담당자 · 정보원 관리자(+ 주간기술동향지 외부 전문가 전용 포털 계정).

## 자료 수집(Phase 4-2)
- **ICT 정보 수집**: 상단에 최근 수집 시각·24시간 신규·검토할 자료·실패 정보원이 보인다. **지금 수집**(관리자·정보원 관리자·검토자·승인 담당자)은 서버가 모든 활성 정보원을 순서대로 수집하며 끝나면 목록이 갱신된다. 각 자료의 **원문 열기**(새 탭)·**상세 분석**·**후보 등록**을 쓸 수 있다. 수정된 원문은 `v2` 배지로 표시되고 이전 버전은 보존된다.
- **출처·수집 관리**: 정보원 등록·편집·연결 테스트·지금 수집(작업 진행·취소)·비활성화. 접속이 거부되면 '접속 제한'과 사유가 표시되며 우회하지 않는다.
- 자동 수집은 작업자가 정보원별 주기(예: 6시간·12시간)에 따라 실행한다. 웹사이트를 열어 두지 않아도 된다.
