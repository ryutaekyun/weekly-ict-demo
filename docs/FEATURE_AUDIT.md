# 통합 웹사이트(apps/web + apps/api) 기능 상태 — Phase 3-5 갱신 (2026-10-26)

위 표는 정적 시연 `index.html`의 감사 결과이며 **`index.html`은 변경하지 않았다**. 아래는 실제 구동되는 통합 웹사이트의 상태다.
상태 구분: **실제 작동**(서버에 저장되고 브라우저에서 끝까지 확인됨) / **구현되었으나 화면 미연결** / **정적 시연 전용** / **미구현** / **실행 오류**.
"검증"은 pytest(225건 통과), Playwright E2E(26건 통과), tsc 기준이다. Word·PowerPoint 실제 열람은 **미검증**이다(LibreOffice 변환 확인만 수행).
